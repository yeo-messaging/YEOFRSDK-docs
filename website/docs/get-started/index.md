# Get started

Pick the page for the technology your app is built with. Each one takes you from an empty integration to a first enrolment and a first recognition.

| Your app is built with | Start here | Full integration guide |
|---|---|---|
| Kotlin or Java | [Android](android.md) | [API reference](https://yeo-messaging.github.io/yeofrsdk-android-docs/0.2.29/) |
| Swift | [iOS](ios.md) | [API reference](https://yeo-messaging.github.io/YEOFRSDK-docs/0.11.2/documentation/yeofr/) |
| React Native | [React Native](react-native.md) | [React Native guide](https://yeo-messaging.github.io/YEOFRSDK-docs/rn/0.5.2/) |
| Flutter | [Flutter](flutter.md) | [Plugin README](https://github.com/YEOMessaging/yeofr-flutter/tree/v0.5.1#readme) (access from YEO) |
| Capacitor | [Capacitor](capacitor.md) | [Capacitor guide](https://yeo-messaging.github.io/YEOFRSDK-docs/capacitor/0.5.0/) |
| Cordova | [Cordova](cordova.md) | [Cordova guide](https://yeo-messaging.github.io/YEOFRSDK-docs/cordova/0.5.0/) |

Not sure between Capacitor and Cordova? If your project has a `config.xml` and a `platforms/` folder at its root, it is a Cordova app. If it has `capacitor.config.ts` or `capacitor.config.json`, it is a Capacitor app.

Read [Before you start](before-you-start.md) first. It lists what to ask YEO for and what every platform needs.
