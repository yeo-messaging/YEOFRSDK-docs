# What's new

These docs always describe the current published versions. This page shows what changed in each release, and where to find the docs for that version.

If your app is on an earlier version, use the docs for your version. Some answers on this site may not apply to it. If you need answers for a specific version, [contact YEO](../support.md).

## Current versions

| Product | Version | What changed | Do users re-enrol? | Docs for this version |
|---|---|---|---|---|
| Capacitor | 0.5.0 | First release, on Android 0.2.29 and iOS 0.11.2 | Does not apply | [Capacitor guide 0.5.0](https://yeo-messaging.github.io/YEOFRSDK-docs/capacitor/0.5.0/) |
| Cordova | 0.5.0 | First release, on Android 0.2.29 and iOS 0.11.2 | Does not apply | [Cordova guide 0.5.0](https://yeo-messaging.github.io/YEOFRSDK-docs/cordova/0.5.0/) |
| Android | 0.2.29 | Runtime libraries now meet Google Play's 16 KB page size requirement. No API or behaviour change. | No, from 0.2.28 | [API reference 0.2.29](https://yeo-messaging.github.io/yeofrsdk-android-docs/0.2.29/) |
| React Native | 0.5.2 | Moves to Android 0.2.29. The Android camera view delivers events in a way that works with newer React Native versions. | No, from 0.5.0 or 0.5.1 | [React Native guide 0.5.2](https://yeo-messaging.github.io/YEOFRSDK-docs/rn/0.5.2/) |
| Flutter | 0.5.1 | Moves to Android 0.2.29, with the same 16 KB change. No API or behaviour change. | No, from 0.5.0 | [Plugin README](https://github.com/YEOMessaging/yeofr-flutter/tree/v0.5.1#readme) (access from YEO) |
| iOS | 0.11.2 | Updates the on-device liveness check. Used by Capacitor and Cordova. | No, from 0.11.0 | [API reference 0.11.2](https://yeo-messaging.github.io/YEOFRSDK-docs/0.11.2/documentation/yeofr/) |

## Earlier versions

| Product | Version | What changed | Do users re-enrol? | Docs for this version |
|---|---|---|---|---|
| Android | 0.2.28 | New on-device recognition and liveness, framing hints, a new private Maven repository, and a required credential. | **Yes,** from any earlier version | [API reference 0.2.28](https://yeo-messaging.github.io/yeofrsdk-android-docs/0.2.28/) |
| iOS | 0.11.0 | New on-device recognition and liveness. Used by React Native and Flutter. | **Yes,** from any earlier version | [API reference 0.11.0](https://yeo-messaging.github.io/YEOFRSDK-docs/0.11.0/documentation/yeofr/) |
| React Native | 0.5.0, 0.5.1 | Move to Android 0.2.28 and iOS 0.11.0, with `isLive` and framing hints. 0.5.1 changes documentation only. | **Yes,** from 0.4.x or earlier | [React Native guide 0.5.0](https://yeo-messaging.github.io/YEOFRSDK-docs/rn/0.5.0/) |
| Flutter | 0.5.0 | Moves to Android 0.2.28 and iOS 0.11.0, with `isLive` and framing hints. | **Yes,** from 0.2.x or earlier | Ask YEO for access |

Moving from an older version? See [Upgrade and re-enrol](../guides/upgrade.md).
